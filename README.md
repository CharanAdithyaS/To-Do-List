# To-Do List App

A simple, clean To-Do List application built with React and Vite.

## GITHub Repository link

 - Link: https://github.com/CharanAdithyaS/To-Do-List


## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit existing tasks (click the ✏️(Emoji) button or double-click the task text)
- Filter tasks by All / Active / Completed
- Live task counter in the header

## Tech Stack

- React 18 (functional components + hooks)
- Vite (project setup and dev server)
- Plain CSS (no external UI library needed)


## How to Run the App

### Requirement

Make sure you have **Node.js** (v16 or higher) installed on your machine.  
You can check by running:

```bash
node -v
```

### Steps

1. **Install dependencies**:

```bash
npm install
```

2. **Start the development server**:

```bash
npm run dev
```

5. **Open your browser** and visit the URL shown in the terminal (usually `http://localhost:5173`).

---

## Build for Production

To create a production-ready build:

```bash
npm run build
```

The output will be in the `dist/` folder.
